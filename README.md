# Demo · Sistema de gestión Molins

Prototipo navegable de demostración. **Datos de ejemplo**: las consultas, los clientes y las campañas
son ficticios. Las propiedades y sus fotos son reales, tomadas del sitio público de la inmobiliaria.

- **El sistema** → `index.html`
- **El portal público** → `portal.html`, también accesible desde "Mi portal web" dentro del sistema

Se entra eligiendo con qué usuario mirar: **Francisco** (administrador, ve todo) o **Luis**
(vendedor, ve solamente Aires de San Lorenzo). El conmutador de arriba a la derecha permite cambiar
en cualquier momento.

Sitio estático, sin dependencias ni instalación.
